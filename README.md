# .github

Специальный репозиторий уровня профиля GitHub. Два назначения:

1. **`profile/README.md`** — отображается на главной странице [github.com/Lex226](https://github.com/Lex226).
2. **`.github/*`** (ISSUE_TEMPLATE, `pull_request_template.md`, `CONTRIBUTING.md`) — community health defaults, автоматически применяются GitHub к любому репозиторию, у которого нет своих аналогичных файлов.

Полные стандарты ведения репозиториев ведутся в приватном репозитории. Здесь — только шаблоны и точки входа, чтобы изменение правила требовало правки в одном месте.

Репозиторий публичный — это требование GitHub для работы profile README и community defaults; чувствительные детали (клиенты, инфраструктура, ссылки на приватные репозитории) сюда не попадают.
