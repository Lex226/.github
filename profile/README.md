# Alex Esco

Разработчик 1С и BI-инженер: строю аналитику на данных из 1С — от выгрузки в SQL Server до моделей и отчётов в Power BI.
Процессы разработки веду в GitHub и автоматизирую рутину с помощью скриптов и AI-агентов.

## Основное направление

**1С → SQL Server → Power BI**

- ETL по слоям Bronze → Silver → Gold на T-SQL
- DAX-модели и отчёты Power BI поверх Gold-слоя
- Data contracts для источников: поля, grain, правила качества
- Grain-тесты и проверки качества данных перед публикацией
- Lineage и impact analysis: что затронет изменение объекта 1С или SQL
- Единые соглашения об именовании SQL и rollback-скрипт к каждому изменению

## Как я работаю

Все репозитории ведутся по единому стандарту: архитектурные решения фиксируются в ADR, рабочая сессия завершается session-снапшотом, задачи и находки живут в GitHub Issues с общим набором labels (`stage:*`, `priority:*`), а новые проекты стартуют из общего шаблона репозитория. Стандарты ведутся в приватном репозитории.
